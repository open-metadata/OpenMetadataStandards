# AgentExecution

Agent Execution entity representing a single execution run of an AI agent. Tracks inputs, outputs, data lineage, performance metrics, and errors for observability and governance.

**Source schema:** `schemas/entity/ai/agentExecution.json`

## Properties

The following table summarizes the direct properties defined by this schema.

| Property | Type | Description |
|---|---|---|
| `id` | `reference or object` | Unique identifier of the Agent Execution |
| `agent` | `reference or object` | AI Agent that was executed |
| `agentId` | `reference or object` | ID of the AI Agent (for indexing) |
| `timestamp` | `reference or object` | Execution start timestamp |
| `endTimestamp` | `reference or object` | Execution end timestamp |
| `status` | `reference or object` |  |
| `input` | `string` | Input provided to the agent |
| `output` | `string` | Output generated by the agent |
| `modelCalls` | `array` | LLM model calls made during execution |
| `dataAccessed` | `array` | Data sources accessed during execution - KEY FOR LINEAGE |
| `toolCalls` | `array` | Tool calls made during execution |
| `metrics` | `reference or object` |  |
| `errorMessage` | `string` | Error message if execution failed |
| `errorStack` | `string` | Error stack trace |
| `complianceChecks` | `array` | Compliance checks performed |
| `executedBy` | `string` | User or system that triggered the execution |
| `sessionId` | `string` | Session ID for grouping related executions |
| `environment` | `string` | Environment where execution occurred |
| `agentVersion` | `string` | Version of the agent at execution time |
| `metadata` | `object` | Additional execution metadata |
| `deleted` | `boolean` | When true, indicates the entity has been soft deleted |
